結論から言うと、**タイルごとの「回転」「削除」ボタンは冗長寄り、「確認」ボタンは不要**だと思います。ただ、全部消すのではなく整理する方向をおすすめします。

## 各ボタンの評価

**確認（拡大プレビュー）**
ダブルクリックで同じことができるので、ボタンとしては重複です。ただ、ダブルクリックは発見しにくい操作なので、ボタンを消すなら「ダブルクリックで拡大」のヒントが目に入る位置にあれば十分です（すでにヘッダー右側に書いてあるので、そこは対応済みです）。カード下部の一番目立つ位置を占めている割に、使用頻度は高くないはずです。

**回転・削除**
- ツールバーに「左90°/右90°/削除」があり、選択状態に対して動くので、タイルごとのボタンと機能が完全に二重になっています。
- 一方で、**スキャン図面の回転は「1枚だけ直す」操作が中心**なので、タイル上で完結できる価値は実際にあります。選択→ツールバーより1ステップ少なくて済みます。
- 逆に、削除ボタンは**誤クリックのリスクが大きい**のが問題です。カード下部に回転と並んでいるため、結合作業中のマウス操作で触れやすい位置です。

## 提案

1. **削除ボタンはホバー時のみ表示**（カード右上に小さく）にする。常時表示をやめるだけで誤操作が減り、見た目もすっきりします。
2. **回転も同様にホバー表示**にする。回転ボタンは1枚ずつ直す用途で残す価値があります。
3. **「確認」ボタンは廃止**し、ダブルクリックと、ホバー時の拡大アイコン（虫眼鏡）に置き換えます。
4. 常時表示のボタン列がなくなるので、**サムネイルを大きくできます**。ここが一番のメリットです。ページ右上のページ番号を読む用途なので、サムネイルが大きいほうが確認作業に直結します。

## 他の懸念点

**1. ページ番号の確認に関して（最重要）**
主な目的が「過不足と順序の確認」で、元ページの右上に番号が入っているなら、現状のサムネイルでは番号が小さくて読めません。次の工夫が効きそうです。
- 「表示：中」のサイズ切替を大きめにしたとき、右上が読めるかを確認する
- 欠番・重複・逆順を**自動検出して警告**する（OCRでページ番号を読む、または元ファイル名とページ番号の連続性から検出）。目視確認より確実です。
- 最低限、カードのバッジ（#1〜）と元ページ番号（p.1〜）が見えているので、**「元ページ番号が飛んでいる箇所」を強調表示**するだけでも、抜け漏れチェックに役立ちます。

**2. 削除の取り消し**
「戻す/やり直し」があるのは良いです。ただ、削除は**確認ダイアログなしで即実行**でしょうか。Undo があるなら確認は不要ですが、Undo の履歴が保存後・再読み込み後も有効か、複数選択削除も1回のUndoで戻るかは確認してください。

**3. 複数選択状態での個別ボタン操作**
スクリーンショットでは #1, #2, #3, #6 が選択されています。この状態で #4 の「削除」を押したとき、**#4だけ消えるのか、選択中の4枚が消えるのか**が曖昧になりがちです。個別ボタンは常に「そのカードだけ」に作用するよう統一し、挙動が分かる見た目にしておくと事故が減ります。

**4. 選択状態の視認性**
選択済みが青枠、#6だけ黒枠（フォーカス？）と2種類あります。意図通りなら良いですが、「選択」と「フォーカス」の区別が利用者に伝わりにくいかもしれません。

**5. 異なる用紙サイズの混在**
Excel出力のA4と、スキャン図面のA3などを結合すると、サムネイルの比率が揃わず、レイアウトが崩れます。出力時にサイズを揃えるか、そのまま保持するかを選べるとよいです。

**6. 大量ページ時の性能**
26ページなら問題ありませんが、数百ページになるとサムネイル生成が重くなります。遅延読み込み（画面内のみ描画）とサムネイルのキャッシュを考えておくとよいです。

**7. ファイル名の見分け方**
カードに「ファイル名 + p.番号」が出ているのは良い設計です。ただ、同名ファイルを複数追加した場合に区別がつかなくなるので、ファイルごとに色の帯を付けるなど、**由来ファイルの色分け**があると結合時の確認が楽になります。

**8. キーボード操作**
ツールバーが豊富な分、`Delete` キーで削除、`Ctrl+Z`/`Ctrl+Y` で Undo/Redo、`R` で回転といったショートカットがあると、ボタンを減らしても操作性が落ちません。むしろ、ボタン削減の代替としてショートカットを整えるのが一番効きます。

## まとめ

優先度順に並べると、
1. 「確認」ボタン廃止（ダブルクリックと重複）
2. 削除・回転はホバー表示化（誤操作防止とサムネイル拡大）
3. ページ番号の欠番・重複の自動検出（目的に直結）
4. 複数選択時の個別ボタンの挙動を明確化

サムネイルが大きくなると目視確認の精度が上がるので、UIの整理は見た目だけでなく本来の目的にも効くはずです。
