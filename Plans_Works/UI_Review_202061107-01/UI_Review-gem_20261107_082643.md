### タイル個別ボタン（確認・回転・削除）の冗長性について

**結論として、各タイルの常設操作ボタンは冗長であり、削除または表示形式の見直しを推奨します。**

主な理由は以下の3点です。

* **画面上部のグローバルツールバーとの重複とメンタルモデルの不一致**
Shift/Ctrlキーによる複数選択を実装しているため、主操作は「選択して上部バー（またはショートカット）で一括実行」に集約されます。個別ボタンが常時並んでいると、1ページずつチマチマ操作する導線が視覚的に強調され、複数選択機能の活用を阻害します。
* **誤操作リスク（Fittsの法則）**
1つのタイル内に「確認・左回転・右回転・削除」の4ボタンが狭い間隔で密集しています。特に削除ボタンが他の操作の真隣にある構造は、並び替えや選択のドラッグ開始時などに誤クリックを誘発しやすくなります。
* **サムネイル有効面積の圧迫**
カード下部にボタン行を常に確保している分、プレビュー画像の縦方向サイズが削られています。後述する「右上のページ番号の確認」において、サムネイルが少しでも小さくなることは業務効率上のマイナス要因です。

**代替案：**

1. **ホバー時のみオーバーレイ表示**：普段は非表示にしてサムネイル領域を最大化し、カードにマウスホバーした時のみ右肩や中央にフローティングアイコンを出す。
2. **完全撤去＋右クリック（コンテキストメニュー）**：個別操作は右クリックメニューに集約し、基本は「ダブルクリックで拡大」「選択して上部ツールバー/キーボードで操作」に絞る。

### その他の懸念点と改善提案

提示された使用シーン（Excel出力作業書のページ過不足・順序確認、スキャン図面の回転）に照らし合わせると、以下の点に懸念があります。

#### 1. 右上のページ番号がサムネイル上で読めない問題（推論の確度：高）

* **懸念**：
Excelのヘッダーや本文右上に配置されたページ番号（一般的に10〜12pt程度）は、現在の「中」表示の縮小解像度では文字が潰れて判読できない可能性が極めて高いです。結果として、確認のために毎回ダブルクリックで拡大プレビューを開くことになり、作業テンポが著しく低下します。
* **対策案**：
* **ルーペ機能（ホバーズーム）**：サムネイルの右上にマウスを載せた瞬間だけ、その領域を等倍拡大するポップアップ（ルーペ）を出す。
* **「大」表示の最適化**：右上にある「表示：中」を「大」にした際、ページ番号が直接視認できるサイズまで拡大できるようにする。



#### 2. モーダル式プレビューによる全体文脈の喪失（推論の確度：中）

* **懸念**：
画像1のように、ダブルクリックで全画面に近いモーダルを開くと、背後のグリッド（前後のページ順や全体の流れ）が隠れてしまいます。「今どのファイルの間を見ているか」「ここからどこへ移動させたいか」を把握しながら作業する場合、モーダルの開閉を繰り返すのはストレスになります。
* **対策案**：
* 画面を左右に分割し、「左：サムネイル一覧」「右：選択中ページの常時プレビュー（ピンチズーム・回転可能）」という2ペイン構成にする。
* これにより、サムネイルをキーボードの矢印キーで送るだけで、右ペインに中身が即座に表示され、過不足確認の速度が格段に向上します。



#### 3. スキャン図面と作業書の判型混在（推論の確度：高）

* **懸念**：
Excel作業書はA4（縦または横）が主流ですが、図面はA3横などの大きな判型が混在することが一般的です。
現在のタイル枠がA4縦固定に近いアスペクト比の場合、A3横の図面が上下に大きな余白を持って極小表示されたり、意図しないトリミングを受けたりする恐れがあります。
* **対策案**：
* タイル内のプレビュー描画領域をアスペクト比追従（レターボックス表示）にし、横長文書でも外枠が崩れないようにする。
* 縦・横・用紙サイズ（A4/A3等）をカード上部または下部にバッジ表示（例: `A3横`）すると、回転ミスやサイズ混在が一目で判別できます。



#### 4. 元ファイル境界の識別性（推論の確度：中）

* **懸念**：
カードヘッダーに元ファイル名（`事前周知_...`）が表示されていますが、ファイル名が長いと中央や末尾が省略されて「どのExcelから出力した塊か」の境界線が埋もれやすくなります。
* **対策案**：
* 取り込んだファイルごとにカード上部（または枠線）をカラーコードで色分けする（例: ファイルAは青帯、ファイルBは緑帯）。
* これにより、「ファイルAの全ページの後ろにファイルBが来ているか」「ページが別ファイルの途中に混ざっていないか」を視覚的に一瞬で照合できます。



#### 5. キーボードショートカットの実装状況

マウスでのD&Dやツールバー操作だけでなく、以下のショートカットがあるかどうかで仕分け速度が大きく変わります。

* `Delete` / `Backspace`：選択ページの削除
* `Ctrl` + `Z` / `Ctrl` + `Y`：アンドゥ・リドゥ
* `R` / `L`（または `Ctrl` + `→` / `←`）：選択ページの90度回転
* `Space`：クイックプレビュー（押している間だけ拡大表示、またはモーダル開閉）
* `Ctrl` + `A`：全選択
