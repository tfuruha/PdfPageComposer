仕様概要書 (SpecSummary20261106.txt)
プロジェクト名: PdfPageComposer
作成日: 2026-11-06
================================================================================

1. 目的と概要
   複数のPDFファイルを読み込み、ページ単位でのプレビュー確認、結合、不要ページの削除、
   ページ順序の並び替え、特定位置へのページ挿入、およびページの90度単位回転を行い、
   新しいPDFファイルとして出力するデスクトップアプリケーションを提供する。

2. ターゲットプラットフォーム
   - 本番動作環境: Linux, Windows
   - CGoに依存しない構成とすることで、OS固有のC/C++ネイティブライブラリ問題を排除し、
     両OSでの安定したビルド・配布を実現する。

3. 技術スタック選定
   - アプリケーションフレームワーク: Wails v2 (v2.13.0)
   - バックエンド言語・ライブラリ: Go + pdfcpu (github.com/pdfcpu/pdfcpu)
   - フロントエンド: Svelte + TypeScript + Vite (パッケージ管理: Bun)
   - PDFプレビュー描画: Mozilla PDF.js (pdfjs-dist) による HTML5 Canvas レンダリング
   - スタイリング: Scoped CSS + CSS Custom Properties (外部CSSフレームワーク非依存)
   - コーディング規約: Google Style Guide (Go / TypeScript)

4. 主要機能要件
   (1) PDFファイルの追加・挿入
       - ファイル選択ダイアログからの複数PDF読み込み
       - ウィンドウへのドラッグ＆ドロップによるPDF追加
       - 末尾への追加、および指定位置（選択ページの前/後・カード間）への別PDF挿入
   (2) ページプレビュー機能
       - 全ページのサムネイル一覧グリッド表示（元ファイル名、元ページ番号、通し番号表示）
       - 任意のページをクリック/選択して拡大確認できるモーダルプレビュー表示
         （前後ページ移動、ズーム倍率変更、回転・削除操作が可能）
   (3) ページ編集機能
       - ドラッグ＆ドロップによるページ順の並び替え（単一および複数選択対応）
       - 複数ページ選択（クリック、Ctrl/Cmd+クリック、Shift+クリック、全選択/解除）
       - ページの削除（単一・複数一括削除）
       - ページの回転（90度単位の左/右回転、プレビューおよび出力PDF双方に反映）
       - 操作履歴の Undo / Redo 機能（最大50ステップ）
   (4) PDF出力機能
       - ネイティブ保存ダイアログによる出力先ファイルパス指定
       - バックエンドの pdfcpu によるロスレス（ベクター品質維持）でのページ合成・回転・保存

5. 設計・実装原則
   - コード変更時は対応する docs/*.md の設計仕様書と整合性を保つこと。
   - 正常系だけでなく、破損PDFや存在しないパス、空ページ出力などの異常系エラーハンドリングを実装し、
     UI上でユーザーに分かりやすく通知すること。
