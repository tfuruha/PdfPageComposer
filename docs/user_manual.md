# PdfPageComposer ユーザー説明書（利用ガイド）

**PdfPageComposer** は、複数のPDFファイルを直感的な操作で結合、ページ削除、並び替え、回転、挿入し、新しいPDFとして書き出すことができるデスクトップアプリケーションです。

## 1. 主な特徴

- **完全ローカル処理で安心・安全**:
  機密文書や個人情報を含むPDFも、外部サーバーにアップロードされることなく、すべてお使いのPC内で安全に処理されます。
- **ロスレス（無劣化）合成**:
  文字やベクター図形のシャープさをそのまま保った高品質なPDF出力を行います。
- **直感的なサムネイル一覧表示**:
  元ファイル名、元ページ番号、並び替え後の通し番号が一目でわかります。
- **柔軟なページ編集**:
  マウス操作による直感的な並び替え、複数選択による一括移動・回転・削除、最大50ステップの取り消し（Undo/Redo）に対応しています。

## 2. 動作環境・事前準備

### Windows
- **対応OS**: Windows 10 (64bit) / Windows 11 (64bit)
- **必要なランタイム**: **Microsoft Edge WebView2 ランタイム**
  - ※通常のWindows 10/11には標準でインストールされています。もし起動時に「WebView2が見つかりません」といったメッセージが表示される場合は、マイクロソフト公式ページより「WebView2 Evergreen ブートストラップ」をダウンロードしてインストールしてください。

### Linux
- **対応OS**: 主要なLinuxディストリビューション（Ubuntu 22.04 LTS / 24.04 LTS 等）
- **必要なライブラリ**: `webkit2gtk-4.1`

---

## 3. 起動方法

特別なインストーラーを実行する必要はありません。

1. 配布された Zip ファイルを任意のフォルダ（デスクトップやマイドキュメント等）に展開（解凍）します。
2. 展開されたフォルダ内にある `PdfPageComposer.exe`（Linuxの場合は `PdfPageComposer`）をダブルクリックして起動します。

## 5. 基本操作ガイド

### 5.1 PDFファイルの読み込み・追加
- **ボタンから追加**: ツールバーの **「PDFを追加」** ボタンをクリックし、ファイル選択ダイアログから追加したいPDFファイル（複数選択可）を選択します。
- **ドラッグ＆ドロップ**: エクスプローラーからPDFファイルを本アプリのウィンドウ上に直接ドラッグ＆ドロップすることでも追加できます。
- **複数ファイル追加時の「読み込み順確認」**:
  - 2つ以上のPDFファイルを一度に追加した場合、自動的に **「ファイル読み込み順の確認」画面** が開きます。
  - OSやエクスプローラーから予期しない順序でファイルが渡された場合でも、ページ展開前に **「名前順 (A → Z)」** ボタンをクリックするだけで、ファイル名に含まれる数字順（1, 2, 10 等）に瞬時に整列できます。
  - リスト行のドラッグや「▲」「▼」ボタンによる手動並び替え、不要なファイルの除外（✕）も可能です。
  - **「展開して追加」** をクリックすると、整列された順序でページカードがワークスペースに展開されます。
  - （※1ファイルのみを追加した場合は、確認画面を挟まず即座に展開されます）

### 5.2 ページの選択
ページの移動や回転、削除を行うには、対象のページカードを選択します。

| 選択操作 | 操作方法 |
| :--- | :--- |
| **単一選択** | ページカードをクリック |
| **キーボード移動** | `←` / `→` 矢印キー（前後のカードに素早く選択移動） |
| **複数選択（追加/解除）** | `Ctrl` キー（Mac環境は `Cmd` キー）を押しながらカードをクリック |
| **範囲選択** | 最初のカードをクリックした後、`Shift` キーを押しながら別のカードをクリック、または `Shift + ← / →` キー |
| **全選択 / 全解除** | ツールバーの **「全選択」** ボタンをクリック、または `Ctrl + A` |
| **選択解除** | 画面の余白部分をクリック、または `Esc` キー |

### 5.3 ページの並び替え
ページの並び替えには、**ドラッグ＆ドロップ** と **カット＆ペースト** の2つの方法があります。

- **ドラッグ＆ドロップ**:
  1. 移動したいページカード（複数選択時は選択されたすべてのカード）をマウスの左ボタンで長押しします。
  2. そのまま挿入したい位置までドラッグします（挿入位置に青いガイドラインが表示されます。画面上下端に近づけると自動スクロールします）。
  3. マウスボタンを離すと、指定位置へページが移動します。
- **カット＆ペースト (`Ctrl + X` / `Ctrl + V`)**:
  1. 移動したいページを選択して `Ctrl + X`（またはツールバーの「✂ 切り取り」）を押すと、対象カードが半透明になります。
  2. 挿入したい位置の前のページをクリックし、`Ctrl + V`（または「📋 貼り付け」）を押すと、その直後に一括移動されます（大量ページの並び替えに便利です）。

### 5.4 ファイル単位の並び替え・一括ソート（📁 ファイル順）
ワークスペースに複数のPDFファイルが含まれている場合、ツールバーの **「📁 ファイル順」** ボタン（2ファイル以上で有効化）から、いつでもファイル単位での順序変更が行えます。

- **一括ソート**:
  - **「名前順 (A → Z)」**: ファイル名に含まれる数字を正しく認識し、自然順（例: `sample1.pdf, sample2.pdf, sample10.pdf`）で昇順ソートします。
  - **「名前順 (Z → A)」**: 降順で逆ソートします。
  - **「リセット」**: 変更前の初期順序に戻します。
- **手動並び替え**:
  - 各行左端のドラッグハンドル（`⋮⋮`）をドラッグ＆ドロップして直感的に順序を変更できます。
  - 各行右側の「▲」「▼」ボタンで1段ずつ上下移動させることも可能です。
- **安心の反映**:
  - **「この順序を適用」** をクリックすると、各ファイル内ですでに編集したページ順序や回転角をそのまま保持した状態で、ファイル全体が一括再配置されます。
  - 適用後でも `Ctrl + Z`（Undo）で直前のページ順序にワンタッチで復元できます。

### 5.5 ページの回転（90度単位）
スキャン時に上下逆さまや横向きになってしまったページを90度単位で回転できます。

- **ツールバー / ショートカット**: ページを選択し、ツールバーの回転ボタンをクリック、またはキーボードの `R`（右90°回転）/ `Shift + R`（左90°回転）を押します。
- **ホバー操作**: 各ページカードにマウスを乗せると下部に現れる半透明の回転アイコン（`⟲` / `⟳`）をクリックします。

### 5.6 ページの削除
- 削除したいページカードを選択し、ツールバーの **「削除」** ボタンをクリック、またはキーボードの `Delete` / `Backspace` キーを押します。

### 5.7 拡大プレビューでの確認
文字が小さくて読めないページや、内容を詳しく確認したい場合は拡大プレビューを利用できます。

- **モーダルプレビュー**: カード下部の「確認」ボタン、カードのダブルクリック、またはカード選択中に `Space` キーを押します。
  - 前後ページ切り替え（`←` / `→`）、拡大縮小（`+` / `-` またはマウスホイール）、回転（`R` / `Shift + R`）、削除（`Delete`）が可能です。
  - `Esc` または `Space` キーで閉じます。
- **右上ホバールーペ**: 各カード右上のページ番号バッジ（`p.X`）や `🔍` アイコンにマウスを乗せるだけで、ページ右上（図面ヘッダーや章見出し・管理番号等）が元PDFの解像度に近い高精細画像（基準幅1400px相当・アスペクト比維持）で拡大ポップアップ表示されます。文字が滲まず、横伸びや歪みもありません。

### 5.8 元に戻す（Undo）・やり直す（Redo）
誤ってページを削除してしまったり、並び順を間違えてしまった場合でも安心です。

- **元に戻す**: ツールバーの **「元に戻す」**（左矢印アイコン）をクリック、または `Ctrl + Z`
- **やり直す**: ツールバーの **「やり直し」**（右矢印アイコン）をクリック、または `Ctrl + Y`（`Ctrl + Shift + Z`）

### 5.9 編集したPDFの保存（エクスポート）
1. ツールバー右側の **「PDFを出力」** ボタンをクリックします。
2. 名前を付けて保存ダイアログが表示されるので、出力先フォルダとファイル名（例: `結合済みドキュメント.pdf`）を指定して「保存」をクリックします。
3. 指定した場所に、並び替え・回転・削除が反映された新しいPDFファイルが出力されます。

### 5.10 新しい作業の開始（新規作成）
PDFの出力・編集作業が完了し、別のPDFファイルの編集を一から開始したい場合は、**「📄 新規作成」** を利用します。

- **操作方法**:
  - ツールバー先頭の **「📄 新規作成」** ボタンをクリック、またはキーボードの `Ctrl + N`（Mac環境は `Cmd + N`）を押します。
  - （画面下部のサブバーにある「すべてクリア」リンクからも同様に実行できます）
- **安心の誤破棄防止ガード**:
  - ページが存在する状態で実行した場合、「現在の編集内容をクリアして、新しい作業を開始しますか？」と確認ダイアログが表示されます。
- **完全なキャッシュ・状態クリア**:
  - 確定すると、ワークスペースの全ページ、読み込み元PDF情報、切り取りバッファ、Undo/Redo 履歴、および内部のPDFドキュメントキャッシュや高解像度画像キャッシュがすべて初期化され、アプリ起動時と同じ初期画面（ドロップゾーン）へ瞬時に復帰します（※サムネイルの表示サイズ設定「小/中/大」は維持されます）。

## 6. ショートカットキー一覧

| キー操作 | 機能 |
| :--- | :--- |
| `Ctrl + N` | 新しい作業を開始（新規作成・確認ダイアログ付き） |
| `←` / `→` | 選択ページを前後に移動（フォーカス移動） |
| `Shift + ←` / `→` | 選択範囲を前後に拡張 / 縮小（エクスプローラー風範囲選択） |
| `Ctrl + X` | 選択中のページを切り取り（半透明表示） |
| `Ctrl + V` | 切り取ったページを選択位置の後に貼り付け（移動） |
| `Space` | 選択ページの拡大プレビューを開く / 閉じる |
| `R` | 選択ページを時計回りに90°回転 |
| `Shift + R` / `L` | 選択ページを反時計回りに90°回転 |
| `Delete` / `Backspace` | 選択中のページを削除 |
| `Ctrl + A` | すべてのページを選択 / 解除 |
| `Ctrl + Z` | 直前の操作を元に戻す (Undo) |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 元に戻した操作をやり直す (Redo) |
| `Esc` | 切り取り状態の解除 / プレビューモーダルを閉じる / 選択解除 |

## 7. よくある質問・トラブルシューティング

### Q1. アプリを起動しても画面が真っ白のまま表示されません。
**A.** Windows 環境で Microsoft Edge WebView2 ランタイムが正常に動作していない可能性があります。Windows Update を実行して最新の状態にするか、Microsoft公式の「WebView2 ランタイム」インストーラーをダウンロードしてインストールしてください。

### Q2. パスワードで保護された暗号化PDFは読み込めますか？
**A.** 現在のバージョンではセキュリティ上の観点から、閲覧パスワードが設定されたPDFファイルの読み込みには対応していません。あらかじめパスワードを解除したPDFをご用意の上ご利用ください。

### Q3. 保存すると画質が落ちたり文字がぼやけたりしませんか？
**A.** 本アプリは画像を再圧縮するのではなく、PDFの内部構造（テキスト情報やベクターデータ、埋め込み画像）をそのまま活かしてページ合成を行います。そのため、元の鮮明さを保ったまま（ロスレスで）保存されます。

### Q4. ページを削除しても、元のファイルは消えませんか？
**A.** はい、元のPDFファイルが変更または削除されることは一切ありません。編集内容は「保存」時に指定した別の新しいPDFファイルとして出力されます。
